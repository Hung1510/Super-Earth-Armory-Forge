Super Earth Armory Forge
========================
Author ............. Hung1510 (formerly released as "Passive Picker v4")
Where it started ... mostlycloudy - Passive Picker v3 / Modular Armor Passives
                     https://ayakamods.com/mods/modular-armor-passives.4350/
                     (the author invited edits: "feel free to mess with the files
                     yourself and maybe you can make a better version")
                     The memory-patching engine, archive format and passive data
                     come from that mod.
Engine lineage ..... mostlycloudy, with credit to SHODAN (as noted in v3)
In-game panel ...... drawing, input and font handling techniques adapted from
                     SHODAN Stat Editor v1.4.1 by SHODAN (public domain / Unlicense)
                     https://github.com/SHODAN-HORAI/SHODAN-Stat-Editor
Source ............. https://github.com/Hung1510/Super-Earth-Armory-Forge
Armor weight ....... the armor kit record layout comes from FileDiver by xypwn
                     (BSD-3-Clause), datalibrary/armor_sets.go
                     https://github.com/xypwn/filediver
简体中文 ........... the Simplified Chinese panel (tools/lang_zh.lua) is hd2modpj's
                     translation from their "Super Earth Armory Forge 简体中文" addon,
                     with the game's official Chinese passive and armor names
日本語 ............. the Japanese panel (tools/lang_ja.lua) uses the game's own Japanese
                     passive and armor names (read from a game install with FileDiver,
                     tools/armor-names/); the rest was translated for the panel
Web builder ........ uses JSZip (MIT) - docs/vendor/
Mascot ............. the idea and behaviour (eyes follow the cursor, boop, dizzy) are from
                     page-mascot by Kamran Ahmed (MIT) https://github.com/nilbuild/page-mascot
                     The web builder's mascot uses its "astronaut" sprite sheets
                     (docs/mascot/, licence copied there); the in-game one is drawn from
                     rectangles and shares no art with it.
Quad Drop .......... Super Earth Quad Drop (tools/quad_drop.lua) is based on "HD2 Support Weapon
                     Quad-Drop" 0.4.2 by Antigravity, https://ayakamods.com/mods/support-weapon-quad-drop.4660/
                     ("Anyone is welcome to use, modify, improve, redistribute, or build upon this
                     mod. Please retain credit to all contributors."). Runs on HD2Runtime by skyeshade.
Loader ............. Bingus Shared Loader (required)
                     https://ayakamods.com/mods/bingus-shared-loader.3861/

Armory Forge's own work: the in-game armory terminal (F7) and its look, loadouts
and quick-swap (F9), undo, share codes, plain-language values, the loadout.ini
config layer (per-effect values, base-perk overrides, several armour stacks,
conflict policy, validation), the web builder, the offline test harness.
